# homeroomkit

담임 운영 키트 — 시간표, 일과운영표, 자리 배치, 역할 배정, 친구탐험 등 교실 운영 도구.

모든 설정은 **구글 시트**에서 관리한다. 앱은 시트를 읽기만 하며, 코드에는 설정값이 없다.

## 구글 시트 연결

앱 첫 화면에서 주소를 한 번 붙여넣으면 브라우저에 저장되어, 다음부터는 바로 열린다.
선생님마다 본인 시트 주소를 넣으면 각자의 학급으로 동작한다.

받아들이는 주소는 두 가지이고, 붙여넣으면 자동으로 판별한다.

### 1. 시트 주소 — 간단하지만 시트가 공개된다

1. 시트에 아래 [시트 구조](#시트-구조)의 탭 8개를 만든다.
   (2번 방식의 **시트 초기 세팅** 을 한 번 돌리면 자동으로 만들어진다)
2. 시트에서 **공유 → 일반 액세스**를 **"링크가 있는 모든 사용자 · 뷰어"** 로 바꾼다.
3. 주소창의 시트 주소를 그대로 붙여넣는다.

링크를 아는 사람은 누구나 학생 명단을 볼 수 있다.

### 2. Apps Script 웹 앱 — 시트를 비공개로 유지

1. 시트에서 **확장 프로그램 → Apps Script** 를 열고 [`apps-script/Code.gs`](apps-script/Code.gs)
   내용을 통째로 붙여넣고 저장한다.
2. 시트로 돌아와 새로고침하면 상단에 **[담임키트]** 메뉴가 생긴다.
   **[담임키트] → 시트 초기 세팅** 을 실행하면 탭 8개가 기본값과 함께 만들어진다.
3. **배포 → 새 배포 → 유형 "웹 앱"** — 실행 계정 **나**, 액세스 권한 **모든 사용자**
4. 나온 웹 앱 URL(`.../exec`)을 붙여넣는다.

시트 자체는 비공개로 둬도 된다. 웹 앱이 소유자 권한으로 대신 읽어주기 때문이다.
웹 앱 URL 을 아는 사람은 시트 내용을 읽을 수 있으므로 URL 은 공유하지 않는다.

시트를 고친 뒤에는 앱 왼쪽 메뉴 하단의 **시트 새로고침** 을 누른다.
읽어온 내용은 브라우저에 캐시되므로 오프라인에서도 마지막 상태로 동작한다.

## 시트 구조

| 탭 | 열 |
|---|---|
| `학급` | 항목 · 값 (학년, 반, 기본학기, 자리행, 자리열) |
| `학생` | 번호 · 이름 · 역할대상(Y) |
| `역할` | 구분(고정/변동) · 역할 · 설명 · 학생번호 |
| `거리두기` | 학생번호1 · 학생번호2 |
| `친구탐험` | 이모지 · 질문 · 난이도(easy/medium/hard) · 필수(Y) |
| `반시간표` | 학기 · 교시 · 월 · 화 · 수 · 목 · 금 |
| `정보시간표` | 학기 · 교시 · 월 · 화 · 수 · 목 · 금 |
| `일과표` | 이름 · 이모지 · 시간 |

- **학기**는 `2026-1` 형식으로 쓴다. 시간표 탭에 등장하는 학기가 곧 앱의 학기 토글 목록이 된다.
- `역할대상` 열을 아무도 표시하지 않으면 전원이 역할 뽑기 대상이 된다.
- 과목·반 색상은 시트가 아니라 `src/data/timetable.ts`, `src/data/teacher-timetable.ts` 에 있다.
  등록되지 않은 이름은 기본 회색으로 표시된다.

기기에 저장되는 것은 자리 비활성/고정 상태, 자리·역할 뽑기 결과, 선택한 학기, 확대 배율뿐이다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입 체크 + 프로덕션 빌드
npm run lint
```
